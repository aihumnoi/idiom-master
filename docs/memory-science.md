# วิทยาศาสตร์การจำ — 7 เสาหลักของ IdiomMaster

## 1. Spaced Repetition (FSRS-lite)
**ปัญหา:** Forgetting Curve ของ Ebbinghaus — ลืม 70% ใน 24 ชม. ถ้าไม่ทบทวน
**วิธีแก้:** ทบทวนก่อนจะลืม
- ใช้ FSRS (Free Spaced Repetition Scheduler) เวอร์ชันย่อ แม่นกว่า Anki SM2
- สูตรย่อ: `next_interval = stability * (9 * R) ` โดย R = retrievability
- 4 ระดับ: Again (รีเซ็ต), Hard (x1.2), Good (x2.5), Easy (x3.5 + bonus)

## 2. Dual Coding Theory (Allan Paivio)
จำด้วย "ภาพ + คำ" แม่นกว่า "คำอย่างเดียว" 2-3 เท่า
- ทุกสำนวนมี Visual Mnemonic แบบ absurd/ตลก/เกินจริง (จำง่าย)
- เช่น "cost an arm and a leg" -> ภาพคนจ่ายเงินด้วยแขนและขาจริงๆ

## 3. Elaborative Encoding
ยิ่งเชื่อมโยงมาก ยิ่งจำแม่น
- Origin (ที่มา): เช่น "raining cats and dogs" มาจากหลังคาฟางสมัยก่อน
- Literal (แปลตรงตัว): ให้เห็นความตลก/ความต่าง
- Story Hook: ประโยคสั้น 1 ประโยคให้จำบริบท

## 4. Retrieval Practice (Testing Effect)
การ "ดึงออก" จำแม่นกว่า "อ่านซ้ำ" 50%
- 5 ระดับความยาก (ไล่จากง่ายไปยาก):
  L1 Recognition: เลือกความหมาย (4 ตัวเลือก)
  L2 Cloze: เติมคำในประโยค
  L3 Scenario: เลือกสำนวนที่เหมาะกับสถานการณ์
  L4 Production: พิมพ์สำนวนจากคำใบ้ภาษาไทย
  L5 Creation: แต่งประโยคเอง

## 5. Varied Context Encoding
เจอคำใน 3 บริบท สมองจะ generalize ได้
- ทุกสำนวนมี 3 ตัวอย่าง: Casual / Business / Academic-Movie
- สลับบริบทตอนทบทวน (Interleaving)

## 6. Interleaving & Desirable Difficulty
เรียนสลับหมวดหมู่ จำดีกว่าเรียนเป็นหมวดหมู่ก้อนเดียว (Bjork)
- ระบบสุ่มหมวดหมู่ตอน Review ไม่ให้ซ้ำหมวดติดกันเกิน 2 ใบ
- เพิ่มความยากเล็กน้อย -> จำลึกขึ้น

## 7. Metacognition + Feedback Loop
รู้ว่าตัวเองอ่อนตรงไหน จะพัฒนาเร็ว
- Weak Map: แสดงสำนวนที่ตกบ่อย
- Leech Detector: ตก 8 ครั้ง -> ส่งไปเรียนใหม่แบบ Story
- Immediate Feedback: เฉลยทันที + อธิบายทำไมผิด
